# Контекст: лабораторная работа 4 «Градиентный бустинг над решающими деревьями»

## Задача
Выбрать из сгенерированных для лабораторной работы 3 точек (x_i; y_i) обучающую выборку из
80 точек. Построить по этой выборке регрессионную модель с помощью градиентного бустинга над
решающими деревьями (упростить критерий ветвления, проверяя не все пары подмножеств, на
которые можно разбить множество X_ц, а только |X_ц| таких пар, выбранных псевдослучайным
образом). Оставшиеся 20 точек использовать как тестовую выборку с метрикой качества RMSE.
Привести график линии регрессии с точками обучающей и тестовой выборок. Сторонние библиотеки
запрещены, Stream API разрешён. Теория — конспект лекций, разделы 1.5 «Решающие деревья» и
1.6 «Ансамблирование моделей», стр. 26–39.

## Прогресс
Программа в пакете `org.example.lab4`: `Main` (генерация точек как в работе 3, параметры и
шаги задания), `Point` (точка), `Node` (узел дерева), `Split` (разбиение на два подмножества),
`DecisionTree` (решающее дерево), `GradientBoosting` (модель), `Metrics` (MSE, RMSE), `Plot`
(график в PNG). Генератор `Lcg` — общий, из пакета `org.example`.

- Точки те же, что в работе 3: тот же код генерации и тот же seed 42, функция e^x.
- Дерево по лекции: узел делит свои точки на два произвольных подмножества; проверяется
  |X_ц| случайных пар, выбирается пара с наибольшим |X_ц|H(X_ц) − |X_л|H(X_л) − |X_п|H(X_п),
  H — средний квадрат отклонения от среднего.
- Предсказание дерева по лекции: x идёт в тот узел, где лежит точка с ближайшей абсциссой;
  в листе — среднее ординат.
- Бустинг по лекции: первое дерево строится по точкам, следующие по антиградиенту
  2(y_i − f(x_i)); f = u_1 + η·u_2 + … + η·u_N.
- Гиперпараметры (в задании не заданы): 40 деревьев, глубина 2, темп обучения η = 0,5.
- Результат (seed 42): RMSE на обучающей 0,2567; RMSE на тестовой 3,1460.
