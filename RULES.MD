# RULES.MD

Контекст высшего уровня: правила и постоянные данные, которые почти не меняются
от работы к работе. Скилл `lab-report` читает этот файл раньше, чем `CONTEXT.MD`.
Файл лежит в корне проекта; сам скилл хранится вне проекта и своих данных о
студенте не имеет.

## Титульный лист — постоянные данные студента

Строки строго в формате `Ключ: значение`; названия ключей менять нельзя, по одному
ключу на строку. Все поля должны быть заполнены реальными значениями — скобок и
плейсхолдеров здесь быть не должно.
